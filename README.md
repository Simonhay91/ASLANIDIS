# Aslanidis Tours. լենդինգ + Telegram

Ֆայլեր՝
- `index.html`: լենդինգ էջը (մեկ ֆայլ)
- `server.js`: փոքր սերվեր, որը ստանում է հայտը և ուղարկում Telegram
- `.env.example`: կարգավորումների օրինակ

## Ինչու է սերվեր պետք
Բոտի token-ը չի կարելի դնել էջի կոդի մեջ. ցանկացած այցելու այն կտեսնի։ Ձևը ուղարկում է հայտը քո սերվերին, իսկ սերվերն արդեն գրում է Telegram։

## Տեղադրում
1. Telegram-ում գրիր **@BotFather**-ին, `/newbot`, ստացիր **token**։
2. Պատվիրատուն (կամ խումբը) նախ գրում է քո բոտին որևէ հաղորդագրություն (խմբի դեպքում՝ բոտը ավելացնում ես խմբում)։
3. Իմացիր **CHAT_ID**-ն. բրաուզերում բացիր `https://api.telegram.org/bot<TOKEN>/getUpdates` և նայիր `chat.id` դաշտը։
4. Պատճենիր `.env.example`-ը `.env`-ի և լրացրու `BOT_TOKEN`, `CHAT_ID`։
5. Աշխատեցրու՝ `node server.js` (պետք է Node 18+)։ Բացիր `http://localhost:3000`։

Հայտը գալիս է Telegram՝ **✅ Ընդունել / ❌ Մերժել** կոճակներով։ Կոճակը սեղմելիս հաղորդագրության կոճակները փոխվում են կարգավիճակով։ Հաճախորդին այդ սեղմումը ոչինչ չի ուղարկում, նա կապ է ստանում ձեռքով՝ թողած հեռախոսահամարով։

## Ինչը պետք է փոխել `index.html`-ում
Ֆայլի վերջում `TOURS` բլոկն է՝ երթուղիների ցանկը և գները (այժմ «հարցրեք»)։ Հեռախոսները և էլ. փոստը գրված են HTML-ում՝ «Հայտ և կոնտակտներ» բաժնում։ Լուսանկարները ներդրված են ֆայլի մեջ։

## Հրապարակում
Ցանկացած VPS-ում կամ Render/Railway/Fly-ում. `node server.js`, միջավայրի փոփոխականներով (`BOT_TOKEN`, `CHAT_ID`)։ Եթե nginx-ի կամ Cloudflare-ի հետևում է, ավելացրու `TRUST_PROXY=1`։

## Լեզուներ
Էջը հայերեն, անգլերեն և հունարեն է։ Լեզուն ընտրվում է վերևի աջ կոճակներից (ՀԱՅ / EN / ΕΛ) և հիշվում է բրաուզերում։ Առաջին այցի ժամանակ ընտրվում է բրաուզերի լեզուն (եթե այն հայերեն, անգլերեն կամ հունարեն է), այլապես՝ հայերենը։ Բոլոր տեքստերը `index.html`-ի `I18N` բլոկում են։ Telegram-ի հաղորդագրությունը միշտ հայերեն է, և դրա մեջ գրվում է, թե հաճախորդը որ լեզվով էջն էր տեսնում։
